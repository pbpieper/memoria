ReadMe — the whole project in one place
Memoria helps someone memorize a text by walking it from easy to hard, section by section. There are two surfaces: this Lab, where the exercise model is defined, and the prototype app, where a learner actually climbs. Both read the same data file, so anything changed here shows up there. Start at the top if you have never seen this before.
The one idea
An exercise is not a fixed thing — it is a point in a space. Memorizing a text is walking that space from easy to hard, section by section, until the whole piece is yours. Every view in this Lab is a different projection of that same space.
01 · The model
Three axes — the dials every exercise sets
Grade
cognitive demand — Meet → Recognize → Recall → Produce → Perform. The climb. What the brain is asked to do.
Modality
the channel — Read · Write · Speak · Listen. Which sense does the work.
Scaffold
support strength — full text → first-letters → nothing. How much help is shown. The continuous difficulty dial.
A concrete exercise = { grade, modality, scaffold }. Speed-read and Cloze are not different exercises — they are different points. Slide the scaffold and one becomes the other.
02 · The spine
Five levels, one per step of the climb
01
Meet
First contact. The text is fully shown; the job is exposure — read it, hear it, type along with it.
02
Recognize
The text is partly hidden. You confirm you know what belongs in the gaps — cloze at 25%, first letters.
03
Recall
Most of the help is gone. You pull the words back rather than recognize them — cloze at 50% and up.
04
Produce
Nothing shown. You write or speak the section cold, start to end.
05
Perform
The whole piece, cold, at speed, and eventually for a live listener.
The five grades are a spine, not a cage. A grade can hold all four modalities. Consolidate exercises that are the same dial at different settings; separate ones that genuinely are not.
03 · Structure
Core, support, and why the roadmap is a tree
Core exercises are the must-pass spine: clear one and the next unlocks. Support exercises hang off a core node as side-loops — a learner who stalls on cloze 50% drops into a speed-read lap and comes back. Support is optional by default, which is what turns a linear sequence into a branching roadmap.
A step is a rotation of one scaffold across modalities — not a single drill. The first-letters step: read it from the first letters, write each line filling gaps with the letters as help, speak it from the same scaffold. One support, three channels. You clear the step by finishing its rotation.
Bridges sit between steps. A bridge is a milestone the learner has to actually do — section the text, read the first-letters version aloud end to end — not a box they tick.
04 · Data
Every property an exercise carries
These are the fields the detail editor writes, and the same fields you can filter, sort, and lay the Matrix out by.
name
What the learner sees. Free text.
code
Auto-derived, e.g. 3.1W — step number, sub-step, modality letter. It follows level and order rather than being set directly.
categories
The modality channel: Reading · Listening · Writing · Speaking. Drives node colour everywhere.
level
Which of the five grades it sits at. Sets its band in the Roadmap and its row in the Matrix.
kind
core (must-pass spine) or support (optional side-loop).
family
The tool it belongs to — Cloze, Speed-read, First-letters, Perform. One family recurs across levels at rising difficulty; families are candidates to merge into a single parametric exercise.
support
0–100. How much text is shown. 100 = full text, 0 = nothing. The scaffold dial; also drives the scaffold band used by filters, sorting and the Matrix.
demand
0–100. Take-in → perform. Roughly how far along the climb the exercise sits inside its level.
graded
Whether the run produces a score the engine can act on, or is just exposure.
cp
Checkpoint: none (flows straight through), self (learner marks it done), hard (gate — nothing past it unlocks until it is passed).
active
On/off. Off keeps the exercise here but hides it from the prototype and draws it dashed in every Lab view. This is the only visibility switch — there is no separate draft state.
spec
One line: what the learner actually does. Written for a builder, not for marketing.
notes
Anything else — open questions, why it exists, what it might merge into.
mods
Steps only. Which modalities the rotation covers.
05 · Using the Lab
What each view is for
Roadmap — the default view
The climb as a tree. The core spine runs down the middle; support loops branch off it. The left column carries the prose for each step and the bridge out of it; the right column shows what a learner can freely pick at a chosen floor. Drag a node sideways to change its sub-step order, or across a band to re-level it. Use it to think about sequence.
Table
Every exercise as an editable card. Filter by any property, sort by any property, edit inline, add new ones. Use it to audit and bulk-edit.
Matrix
A cross-tab of the set. Pick any property for columns and any for rows — category × level is the default, but family × scaffold or core/support × level answer different questions. Empty cells are the interesting part: they are gaps in coverage. Drag a chip into another cell to reassign it. Use it to find holes.
Detail editor
Click any node in any view to open it. Same panel everywhere: all properties, an on/off toggle, Practice, and Delete with a confirm. Find in Matrix / Roadmap jumps to the same node in another view.
Sample text and Simulate
The passage at the top drives every run. Practice on one exercise runs it against that text; Simulate walks the whole ladder start to finish, so you can feel the sequence rather than read it.
06 · Using the prototype
What a first-time learner does
1
Open the library and add a piece — paste the text you want to memorize.
2
Break it into sections. Sections are the unit of practice; the whole piece comes later.
3
Climb. Each floor shows what is unlocked, what is cleared, and what is still locked. Pick freely from what is open — the order inside a floor is yours.
4
Cross a bridge to reach the next floor. Bridges are the one thing that cannot be skipped.
5
The Roadmap tab in the app is the same tree as the one in the Lab. It is where you see how far along the whole piece is, not just the section in front of you.
Exercises switched off in the Lab simply do not appear in the app. That is how the set gets trialled.
07 · The engine
Coupling and refresh
Floor = the weakest section's grade. The whole text is only ever offered at or just below the floor — so the only way to climb the whole is to pull up the laggard section. Cleared exercises return as refreshers (a Read lap before a hard Recall), tracked by a rising metric like wpm — exposure that primes the next rung, not busywork. Takeover: once the floor reaches Produce, the whole becomes primary and sections become its repair shop.
This is the largest piece not yet built. The exercise set and the roadmap are in place; the scheduling logic that couples section progress to whole-piece progress is still to come.
08 · Files
Where everything lives
exercises-data.js
The single source of truth: levels, step prose, bridges, and the full exercise set. Both surfaces read it. Change the model here.
Exercise Lab
This tool. Roadmap, Table, Matrix, and the detail editor. Writes back to the shared store.
Memoria
The learner-facing prototype. Reads the same set; never hard-codes exercises.
support.js
Shared helpers — tree building, family traces, code parsing, reorder logic — so the two roadmaps cannot drift apart.
Both surfaces persist to local storage, so edits survive a reload. If the question is what exercises exist, in what order, and why, it is a data change. If it is how something looks or feels, it is a view change.
09 · Glossary
grade — rung of cognitive demand
modality — read / write / speak / listen
scaffold — how much text is shown
core — must-pass node on the spine
support — optional side-loop off a core node
family — one tool recurring at rising difficulty
parametric exercise — one exercise across a scaffold band
step — a modality rotation at one scaffold
bridge — the milestone between two steps
checkpoint — none, self-marked, or a hard gate
floor — the weakest section grade
coupling — whole tracks the floor
refresher — cleared exercise returning to prime a harder one
takeover — whole becomes primary at Produce
